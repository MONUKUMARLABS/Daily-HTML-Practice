Introduction

Semantic HTML elements provide meaning to the web page structure. They help search engines and assistive technologies understand the content better.

Examples of Semantic Elements

  • <header>: Represents introductory content or a set of navigational links.
  • <nav>: Represents a section of navigation links.
  • <main>: Represents the main content of the document.
  • <section>: Represents a standalone section of content.
  • <article>: Represents a self-contained piece of content.
  • <footer>: Represents footer content for its nearest sectioning content or root element.
